## 实机验证带来的修复

解析器自身的可逆测试不足以证明专有软件接受修改。实机验证发现并修复了 PPSF Events 尾部终止字节丢失、EditorDatas 冗余时序未同步，以及 MIDI 绑定回调提前反映输入的问题。最终 MIDI 状态使用宿主回调，旧驱动协议不再被接受；控制结果需连续回传稳定。

Piapro 重载原生快照后会重新编号文件内的声库 program。本次同一 Solid EVEC 声库从 program 0 变为 2，实际声库名称和区段歌手映射一致。跨文件比较使用实际声库名称，不能依赖固定 program。
